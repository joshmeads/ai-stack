## Codex working rules

- **Verify distinct risks.** Use existing checks first. Extend the relevant behavior suite for distinct risks in changed logic, including important boundaries. For copy, presentation or mechanical edits, inspect the actual output or run an affected existing check. Check affected interactive web behavior in a browser. Run relevant checks after the final edit; repeat only for new evidence.
- **Keep durable output.** Keep useful regression coverage, deliverables and necessary review evidence. Remove only this task's one-off probes and superseded tests once final checks cover their purpose. Use the final reply for handoff and state anything unverified.
- **Clean up after inspecting.** At task completion, inspect tracked, untracked and ignored contents, then remove obsolete owned work. Remove a worktree only when ownership is clear, it is clean and its commits have a branch or remote reference that will remain afterward. Preserve active, dirty, unrelated or uncertain content and assets needed for continuing work. Follow the shared-cache rule above.
